How I work

From rough idea to handoff in four steps.

  1. 1

    Research

    Talk to real users, find the friction, write the problem in one line.

  2. 2

    Wireframe

    Sketch flows in low fidelity so we fix structure before colour.

  3. 3

    Prototype

    Build a clickable version with real type, spacing and states.

  4. 4

    Test and hand off

    Watch people use it, adjust, then deliver specs developers can build from.
